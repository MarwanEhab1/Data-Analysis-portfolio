# Online Store – SQL Server Project
### Project Summary
This project is a basic database design for an online store built using SQL Server.
It includes all the core tables needed to manage products, users, orders, payments, and shipping.

### What I Did
-- DDL – Database Structure
Created tables: Users, Product, Orders, Payment, Shipping, Category, etc.
Defined relationships using primary and foreign keys
Used subtype tables for user roles: Customer, Cashier, Delivery_man
-- DML – Data Insertion
Inserted sample data for products, users, orders, and more
Included multiple product categories and user types
-- DQL – Query-Ready Design
Designed the database so it's ready for analysis and reporting
You can easily write queries like:
Total sales by category
Most used payment method
Orders by customer or shipping type
Top-selling products

---
### Tools & Technologies
- SQL Server
- T-SQL (DDL, DML, DQL)
- Relational modeling
- Normalization and foreign key constraints
